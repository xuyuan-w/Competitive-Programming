# Competitive-Programming

Xuyuan's code collection for competitive programming, since 7/9/26.

## Problems

This folder contains some problems I solved, or upsolved.

For each problem I will put my code and a brief solution of it. Sometimes the solution might be more detailed if I like the problem or have a good mood to write it. If I use inline math in my solution then I won't use `\left` and `\right` as they will mess up the line spacing.

Sometimes I will also paste the PDF statements of the problems here.
